# 试用 Little Internet（5 分钟）

**属于你的互联网一角，永远归你所有。**

Little Internet 是一个装在手机里的小应用，帮你搭建自己的网上小屋。写私密记录、放照片、养一只小幽灵，并且由你精确决定访客能看到什么。所有内容默认只留在你的设备上——除非你主动发布；整个网站还能一键导出，搬到任何地方。

## 准备

- 一台装有现代浏览器（Chrome 或 Safari）的手机。无需账号、邮箱、注册。
- 大约五分钟。

## 打开方式

访问组织者提供的应用地址（或已发布的地址）。在手机上可以"添加到主屏幕"，像 App 一样使用。

## 五个任务

1. **创建你的空间** —— 给小屋起个名字，点"搬进去"。
2. **写一段只给自己看的话** —— 打开"日记"，新建一条。它默认是**私密**的：只有你能在这台设备上看到。
3. **加照片、布置主页** —— 打开"房间"，添加一个照片方块，拖动方块调整位置。
4. **公开一条内容** —— 把某条日记设为"公开"，打开"门 → 在线开放你的小屋"，选一个短地址（例如 `yourname`），点"发布我的小屋"。你会得到一个可以分享的链接。
5. **从访客视角检查** —— 用无痕/隐私窗口打开分享链接，确认能看到公开的那条，但**看不到**你私密的记录。

## 需要知道的事

- **默认私密。** 一条记录在打开它的"门"之前，访客完全看不到。
- **地址归你。** 请保留这个浏览器：发布凭证只存在这里，更新或撤销发布时需要它。
- **随时撤销。** 链接会立即失效；别人已经保存的副本无法收回。
- **可迁移。** 从"门"下载网站 ZIP，放到任何静态托管上。小幽灵、记录、录音照常运行——不依赖本平台。

## 隐私承诺

默认私密 · 为个人而设计 · 天然可迁移。

无账号、无追踪、私密数据不上传服务器。只有你标记公开并发布的内容才会上传。技术细节见 `docs/privacy-audit.md`。

完成任务后请填写反馈表，只需一分钟。
