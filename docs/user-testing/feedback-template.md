# Feedback record / 反馈记录模板

One file (or row) per participant. Do not invent data — record only what a real
participant actually said or did. Participant IDs are anonymous labels.

```
Participant ID:        P__
Date:                  YYYY-MM-DD
Device / browser:      e.g. iPhone 15 / Safari 17, or Pixel 8 / Chrome
Session length:        __ minutes
Facilitator:           __

--- Task outcomes (from task-script.md) ---
Task 1 Create space:        done / stuck / not done   time __ s
Task 2 Private note:        done / stuck / not done   time __ s
Task 3 Photo + layout:      done / stuck / not done   time __ s
Task 4 Publish + share:     done / stuck / not done   time __ s
Task 5 Visitor check:       done / stuck / not done   time __ s
Task 6 Download ZIP:        done / stuck / not done   time __ s
Completion rate:            __ / 6

--- Where stuck (exact step + what they did) ---
Step:                  __
What happened:         __
Hint needed?           yes / no  — which: __

--- Privacy comprehension (quote their words) ---
"Who can see your private note?" -> __
"What happens when you unpublish?" -> __
"Where is your publish credential / what if lost?" -> __
Understood private vs public correctly?   yes / partially / no

--- Open questions (quote exactly) ---
Favourite feature:      __
Least favourite / most confusing:  __
Would you use it again? yes / maybe / no — why: __
Anything else:          __

--- Observations (behaviour, not opinion) ---
Used incognito unprompted?        yes / no
Checked the shared link on same device / another device: __
Mentioned privacy unprompted:     yes / no
```

**Privacy note:** do not record the participant's real diary content, photos,
recordings, publish token, or any credentials. Only behaviour and quoted feedback.
