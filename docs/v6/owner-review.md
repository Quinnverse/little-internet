## Owner 上轮十二项反馈

| 原反馈 | 可实际尝试的动作 | 验证边界 |
|---|---|---|
| 1 入住生硬 | 看插画和房型预览，选衣着，写门牌，Boo 递钥匙 | 可以直接入住，叙事和触感待人评 |
| 2 工具一次性露出 | 打开家园菜单，跟随或跳过三步导览 | 菜单收起，导览可重看。按探索行为逐个解锁仍有提升空间 |
| 3 小人无法控制 | 找到小人，点空地，切换跟随 | 有避开占用格的寻路，别墅新增边厅尚未扩展步行网格 |
| 4 家具无法近看 | 入门后观察家具，再点书桌、唱片机、电脑 | 有近景、真实播放和桌面操作，家具细节仍有差异 |
| 5 穿模和失去视角 | 从门口观察家具，关闭后返回，拖动并复位 | 有回位、缩放和边界，极端角度及手机手势仍待复验 |
| 6 网页自由拖拽 | Website Atelier → Responsive grid，拖动组件上沿手柄 | 桌面浏览器实拖验证坐标变化 |
| 7 网页缩放、重叠、层级 | 拉宽高、设置旋转、图层、组名，再看手机预览 | 实拖验证尺寸变化；手机使用响应式排列，复杂分组重叠仍待手测 |
| 8 手势状态不清楚 | Boo 感知 → 允许摄像头，观察预览与入镜提示 | 可折叠预览、手数、动作、停止按钮；本轮未得到真人识别率 |
| 9 微笑眨眼转头 | 在感知选项开启面部检测 | 本地推理和事件通路已接，真人动作仍待复测 |
| 10 自由对话不自然 | 建立身份后问 Boo 给唱片起名，下一轮追问刚才的名字 | 暂存服本地 Qwen 两轮回答一致，跨题长对话和评委公网访问待验 |
| 11 手消失后绘画串线 | 捏合画线，手离开，张掌返回，再捏合起笔 | 已改为重新落笔，真人跟踪抖动与误触待验 |
| 12 制信缺少引导 | 打开信箱，按提示选纸、写字或放一颗心 | 两个浏览器身份完成送达、收藏、摆放、刷新恢复。两部真手机尚待验证 |

## 参赛前仍要补的证据

- 给一位新用户一个朋友的地址，观察能否自行完成第一次串门、回信并导出自己的主页。保留实际耗时、卡住的位置和使用者原话。
- 录一段连续镜头。门口进入 → 桌面留下一件真实记忆 → 朋友接到信并留在家里 → CRT 导出主页 → 关网重开。已有录像可剪入中段。
- 美术继续检视人物迎门距离、书页文字、织物轮廓、手机近景。不同房型和时间要分别看。当前是风格化低模室内。
- 本轮加入可设置的灯语、手写照片墙、私密祝福信、星空蛋糕仪式。日期联动、跨人发送可配置仪式、全套仪式模板尚未验收。音频和本地录像文件仍在设备的媒体库里，私人 ZIP 尚未携带这些原始文件。
- Kiro 实际开发任务按 Owner 要求暂缓。保留本轮真实 CLI 登录失败记录，等待实际执行后再计入参赛证据。
