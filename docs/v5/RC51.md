# V5.1 review branch

Base: v5/human-internet at 842611a. Review as a stacked PR. Keep production on its existing deployment.

## Local preview

Use Node 24 with SQLite support. Run npm ci and npm run build. Start the single-origin server with PORT=4219 DATA_DIR=./.rc-data APP_DIR=./dist npm run server. Open http://localhost:4219. For camera testing on a separate phone use a trusted HTTPS origin. Each person should use a separate browser profile.

## Owner check (real hardware)

1. Enter a cabin and villa. Zoom into a desk, rotate and reset on a narrow screen.
2. Open the eye control. Enable facial movements, start the camera, then wave, smile, blink, turn, point and make a heart. Stop and confirm the browser light goes out. Repeat after backgrounding.
3. In Letters open Draw, calibrate for 30 seconds, pinch, release, hide the hand and resume. Verify two separate strokes and undo.
4. Friend two independent profiles. Take B offline. From A catch a heart, compose, choose B and confirm. Restart B, tap Boo, keep the actual letter, and place the same gift on the wall and desk. Reload. Remove only the desk instance. Verify the original and wall instance remain.
5. On cellular and Wi-Fi compare the ordinary home against combined tracking. Try denying camera permission and retrying a failed model download.
