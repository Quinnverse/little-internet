# Requirements: Memory gifts

1. A kept letter becomes a private Life Archive entry with provenance (sender, time, mail id); keeping twice changes nothing.
2. The sender's "may show publicly" flag is a ceiling. Without it the gift can never be public, in commands, schema or export.
3. With it, the owner still has to make the entry public; only then the public page shows the letter as SVG.
4. A gift can be hung on the wall; removing the placement keeps the gift; deleting the entry removes its gift record.
5. Backup and restore keep gifts; public export contains only allowed ones.
