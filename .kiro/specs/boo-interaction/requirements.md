# Requirements: Boo interaction

1. Boo reacts to wave (greet), heart (catch), open palm (come over), thumbs up (happy).
2. Reactions are animation and a short message only. They never change, send or publish anything.
3. Boo reacts to a letter arriving only when the server reported a new unread letter.
4. Chat stays local; an optional model may only rephrase Boo's answer, off by default.
5. No statements about the person's emotions.
